# Simple To-Do List (HTML)

A simple to-do list webpage built using HTML. This project demonstrates the basic structure of a web page using forms and lists to display tasks.

## Features
- Displays a list of tasks
- Input field to add new tasks (UI only)
- Clean and simple layout

## Tech Used
- HTML

## How to Use
1. Download or clone the repository
2. Open the `index.html` file in your browser

## Project Status
This is a basic static project built for learning HTML. Functionality can be improved by adding CSS and JavaScript.

## Future Improvements
- Add CSS for better design
- Add JavaScript to make the to-do list interactive
- Allow users to add and remove tasks dynamically
